# CNC ERP Android Demo

未来科技风格安卓端Demo，采用深色主题配合霓虹蓝紫渐变。

## 技术栈

- Kotlin + Android SDK
- Material Design 3
- ViewBinding
- 深色主题 + 霓虹渐变色

## 主题色

| 颜色 | 色值 |
|------|------|
| Neon Blue | #00D4FF |
| Neon Purple | #A855F7 |
| Dark BG | #0A0A0F |
| Dark Card | #13131A |

## 运行

1. 使用 Android Studio 打开此项目
2. 确保已安装 Kotlin 插件和 Android SDK
3. Sync Gradle
4. Run on Device/Emulator

## Demo 演示功能

- 登录页面（未来科技风格）
- 扫码功能入口（开工/报工/过站）
- 车间执行界面
- 数据看板
