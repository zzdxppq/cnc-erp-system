## Executive Summary

CNC加工厂ERP系统面向CNC机加工行业，针对离散型制造企业的核心业务痛点，打造一套集客户管理、报价订单、生产排产、车间执行、品质管控、仓储物流、委外加工、财务人事于一体的综合ERP管理平台。

**核心价值主张**：
- 提升报价效率，实现报价到订单的无缝转化
- 优化自加工与外协混合模式排产，提升产能利用率
- 贯穿客户图纸→工程转化→厂内图纸→打印随单的全生命周期管理
- 精准品质管控（FA首件确认、三次元检测）
- 实时数据看板（产值、交付、逾期、库存）
- 移动端扫码协同（开工、报工、过站、仓储）

## Problem Statement

### 当前状态与痛点

CNC机加工行业具有显著的行业特征：

| 行业特点 | 现状痛点 |
|---------|---------|
| 离散型制造，非标定制件多 | 图纸管理混乱，版本追溯困难 |
| 工序流转复杂（车床→CNC→后加工→表面处理→质检→入库） | 生产进度不透明，交期难以承诺 |
| 委外加工频繁（氧化/电镀/喷涂/热处理/三次元检测） | 外协协同效率低，品质难以管控 |
| 编程管理（新件必编程，历史件可复用） | 工艺知识流失，重复编程浪费 |
| 材料管理按料号+尺寸，下料损耗追踪 | 物料浪费，成本核算不精准 |
| 产能依赖设备（机台号、设备状态、班别） | 机台负荷不均，产能利用率低 |
| 品质检测（三次元、FA首件） | 质检记录不规范，报告留痕难 |

### 影响

- **报价周期长**：缺乏标准化的报价流程和工艺库，报价依赖人工经验，周期长达3-5天
- **交期承诺难**：生产进度不透明，销售难以准确承诺交期，客户投诉率高
- **成本核算粗放**：物料损耗、加工工时、外协费用难以精确归集，产品成本失真
- **信息孤岛**：客户、报价、订单、生产、仓储、财务数据不互通，重复录入效率低

### 现有解决方案的不足

传统通用型ERP难以满足CNC细分行业需求：
- 无法支持图纸全生命周期管理
- 不支持扫码开工/报工/过站的车间执行模式
- 缺乏委外加工的完整协同流程
- 成本核算无法匹配非标定制件的计价逻辑

## Proposed Solution

### 核心概念

构建一套贴合CNC机加工行业的专业化ERP系统，以"图纸管理"和"扫码执行"为双核心，实现从客户需求到成品交付的全链路数字化。

### 关键差异化

| 差异化点 | 方案说明 |
|---------|---------|
| 图纸全生命周期管理 | 客户图纸上传→工程转化→厂内图纸→版本管理→打印随单，全流程追溯 |
| 扫码执行闭环 | 扫码开工→扫码报工→扫码过站，实现车间数字化管理 |
| 自/外协混合排产 | 同一工单支持自加工和委外加工，灵活调度产能 |
| 工艺知识沉淀 | 历史件工艺复用，新件编程任务管理，积累企业工艺库 |

## MVP Scope

### Core Features (Must Have)

| 功能 | 描述 |
|------|------|
| **客户管理** | 客户档案、联系人、洽谈进展、客户保护机制 |
| **报价管理** | 图纸上传、BOM报价预估、审批流程、报价转订单 |
| **订单管理** | 订单录入/审批、进度跟踪、报价转订单 |
| **图纸管理** | 客户图纸上传、在线预览、工程转化、版本管理、打印随单 |
| **BOM管理** | 物料编码规则、BOM维护、BOM版本管理 |
| **生产排产** | 订单转工单、工序排程、机台分配、自/外协判定 |
| **车间管理** | 扫码开工、扫码报工、扫码过站、工序报工、领料管理 |
| **仓储管理** | APP扫码出入库、库存查询、条码管理 |
| **品质管理** | 来料检验、FA首件确认、三次元检测、质检报告 |
| **委外管理** | 外协厂商、委外下单、委外跟踪、委外对账 |
| **系统管理** | 用户管理、角色权限、工作流配置、数据字典 |

### Out of Scope for MVP

| 功能 | 原因 |
|------|------|
| 合同管理（回款计划、利润核算） | 可在订单管理中简化处理 |
| 采购管理（询价比价、到货提醒） | 简化为直接采购流程 |
| 生产派工管理 | 首期聚焦工单管理，派工后续迭代 |
| 计件计时工资 | 考勤+薪酬模块后续迭代 |
| 移动端日程管理、报销 | 对CNC小企业非核心 |
| 多币种管理 | 对CNC小企业非核心 |

### MVP Success Criteria

**验收标准**：
1. 完成客户→报价→订单→生产→车间→仓储→委外→品质的核心流程贯通
2. 扫码开工、扫码报工、扫码过站三个核心场景在1-2个工单上试点验证
3. 报表看板显示产值、交付、逾期关键指标
4. 系统支持100人同时在线，普通查询≤2秒

## Technical Considerations

### Platform Requirements

- **Target Platforms:** Web浏览器（Chrome/Edge/Firefox最新版）、Android 8.0+
- **Browser/OS Support:** Windows 10+，Android 8.0+
- **Performance Requirements:**
  - 普通查询响应时间 ≤2秒
  - 复杂报表响应时间 ≤10秒
  - 支持100人同时在线

### Technology Preferences

- **Frontend:** Vue3 + Element Plus（Web端）、Android Native + Kotlin（APP端）
- **Backend:** Java + Spring Boot 2.7.x（1个Monolith + 2个微服务）
  - 主应用：业务服务（客户/报价/订单/生产/仓储/委外/品质/财务/人事）
  - 微服务1：系统服务（用户/权限/工作流/字典）
  - 微服务2：报表服务（产值/交期/库存/财务报表）
  - API网关：Spring Cloud Gateway（路由 + 认证鉴权）
- **Database:** MySQL 8.0（单主库，通过业务拆分减少单库压力）
- **Cache:** Redis（热点数据缓存、Session共享）
- **File Storage:** 本地存储（2T，按需扩容）/ 阿里云OSS（可选）
- **Task Scheduler:** XXL-JOB（定时任务统一管理）
- **Hosting/Infrastructure:** 单台服务器私有化部署（8核32G起步）

### Architecture Considerations

- **Repository Structure:** 4个代码仓库（主应用 + 系统微服务 + 报表微服务 + 网关）
- **Service Architecture:** 1个Monolith主应用 + 2个独立微服务，避免过度拆分
  - 主应用：核心业务逻辑（客户/报价/订单/生产/仓储/委外/品质/财务/人事）
  - 系统服务：用户管理、权限控制、工作流引擎、数据字典
  - 报表服务：产值统计、交期分析、库存报表、财务报表
  - API网关：统一路由、认证鉴权、日志记录
- **Deployment Architecture:** 单台服务器All-in-One部署，微服务独立部署便于未来扩展
- **Integration Requirements:**
  - 图纸文件存储（本地/NAS）
  - 消息通知（APP推送）
  - 报表导出（Excel/PDF）
  - 扫码硬件对接（扫码枪/PDA）
  - 定时任务（XXL-JOB统一调度）
- **Security/Compliance:**
  - 用户认证（JWT + 验证码）
  - 细粒度权限控制（角色+金额分级）
  - 操作日志完整记录（Spring Boot Audit）
  - 敏感数据加密存储（AES）
- **Transaction Strategy:** 采用编程式事务管理，跨服务场景通过最终一致性解决

## Risks & Open Questions

### Key Risks

| 风险 | 描述 | 影响 |
|------|------|------|
| **扫码推行难度** | 车间操作工年龄偏大，可能抵触扫码操作 | 高：影响核心功能落地 |
| **工艺库积累慢** | 历史工艺复用依赖数据积累，短期效果不明显 | 中：影响报价效率提升 |
| **委外协同复杂** | 外协厂商配合度参差不齐，影响委外流程闭环 | 中：影响交付准时率 |
| **与智邦系统对接** | 需要与现有智邦ERP并行运行，数据同步成本 | 高：影响用户体验 |
| **Monolith扩展性** | 业务模块耦合度高，未来垂直拆分成本大 | 中：影响长期演进 |

### Open Questions

| 问题 | 说明 |
|------|------|
| 是否必须兼容现有智邦ERP的存量数据？ | 影响数据迁移方案 |
| 扫码硬件（扫码枪/PDA）是否需要甲方采购？ | 影响实施成本 |
| 车间WiFi覆盖是否已经完成？ | 影响APP使用可行性 |
| 私有化部署的服务器和网络环境谁来提供？ | 影响部署方案 |

### Areas Needing Further Research

- 操作工扫码习惯培养方案
- 与智邦ERP的数据接口规范
- 不同规模机台的产能评估标准
- 外协厂商的协同平台需求
