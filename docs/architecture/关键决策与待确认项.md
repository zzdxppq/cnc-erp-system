# 关键决策与待确认项

## 🔴 需要确认 (低置信度)

1. **存储方案** — 已改为MinIO对象存储
   - 原因: 企业级对象存储，支持大文件（图纸CAD），兼容S3协议便于未来迁移
   - 备选: 本地/NAS（已放弃）、阿里云OSS（成本更高）

2. **平台选择** — 选择了私有化部署（单台服务器）
   - 原因: CNC行业客户普遍偏好私有化部署，数据安全要求高
   - 备选: 云原生部署（阿里云/腾讯云）

3. **前端UI框架** — 选择了 Vue3 + Element Plus + Tailwind CSS
   - 原因: Element Plus 组件丰富，适合企业级应用
   - 备选: Vue3 + Ant Design Vue

## 🟡 建议审阅 (中等置信度)

4. **API风格** — 选择了 REST
   - 原因: 简单直观，易于调试和文档化
   - 备选: GraphQL（适合复杂查询场景）

5. **Android UI框架** — 选择了 Jetpack Compose
   - 原因: 现代声明式UI，性能优秀
   - 备选: XML布局 + ViewBinding

## 🟢 已按常规处理 (高置信度)

6. **技术栈版本** — 采用了各技术栈的稳定版本（LTS）
7. **架构模式** — 采用了 Monolith + 微服务的混合架构
8. **认证方式** — 采用了 JWT + Refresh Token 方案
