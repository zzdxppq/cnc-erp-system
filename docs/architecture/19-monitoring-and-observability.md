# 19. Monitoring and Observability

## 19.1 Monitoring Stack

- **Frontend Monitoring:** Sentry (JavaScript错误追踪)
- **Backend Monitoring:** Prometheus + Micrometer
- **Error Tracking:** Sentry (后端Java)
- **Performance Monitoring:** Grafana (Dashboards)
- **MinIO Monitoring:** MinIO Console + Prometheus metrics endpoint

## 19.2 Key Metrics

**Frontend Metrics:**
- Core Web Vitals (LCP, FID, CLS)
- JavaScript errors
- API response times
- User interactions

**Backend Metrics:**
- Request rate
- Error rate
- Response time
- Database query performance
- JVM metrics (CPU, Memory, GC)

**MinIO Metrics:**
- Object count per bucket
- Disk usage
- Upload/Download throughput
- Health status
