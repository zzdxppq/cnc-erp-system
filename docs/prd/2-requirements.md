# 2. Requirements

## 2.1 Functional Requirements

- FR1: 客户管理 - 客户档案、联系人、洽谈进展、客户保护机制、积分管理
- FR2: 报价管理 - 图纸上传、BOM报价预估、多级审批、报价转订单
- FR3: 订单管理 - 订单录入/审批、进度跟踪、报价转订单
- FR4: 图纸管理 - 客户图纸上传、在线预览、工程转化、版本管理、打印随单
- FR5: BOM管理 - 物料编码规则、BOM维护、BOM版本管理
- FR6: 生产排产 - 订单转工单、工序排程、机台分配、自/外协判定
- FR7: 车间管理 - 扫码开工、扫码报工、扫码过站、工序报工、领料管理
- FR8: 仓储管理 - APP扫码出入库、库存查询、条码管理
- FR9: 品质管理 - 来料检验、FA首件确认、三次元检测、质检报告
- FR10: 委外管理 - 外协厂商、委外下单、委外跟踪、委外对账
- FR11: 系统管理 - 用户管理、角色权限、工作流配置、数据字典
- FR12: 财务管理 - 应收应付、成本核算、财务报表
- FR13: 人事管理 - 考勤管理、薪资计算、员工档案

## 2.2 Non-Functional Requirements

- NFR1: 普通查询响应时间 ≤2秒
- NFR2: 复杂报表响应时间 ≤10秒
- NFR3: 支持100人同时在线
- NFR4: Web浏览器支持Chrome/Edge/Firefox最新版
- NFR5: Android APP支持Android 8.0+
- NFR6: 单台服务器私有化部署（8核32G起步）
- NFR7: 图纸文件存储支持本地/NAS（2T，按需扩容）
- NFR8: 用户认证采用JWT + 验证码
- NFR9: 操作日志完整记录（Spring Boot Audit）
- NFR10: 敏感数据加密存储（AES）
