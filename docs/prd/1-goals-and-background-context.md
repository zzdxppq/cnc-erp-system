# 1. Goals and Background Context

## 1.1 Goals

- 实现客户→报价→订单→生产→车间→仓储→委外→品质的核心流程贯通
- 扫码开工、扫码报工、扫码过站三个核心场景在1-2个工单上试点验证
- 报表看板显示产值、交付、逾期关键指标
- 系统支持100人同时在线，普通查询≤2秒
- 报价周期从3-5天缩短至1-2天
- 订单交付准时率从70%提升至90%

## 1.2 Background Context

CNC加工厂ERP系统面向CNC机加工行业，针对离散型制造企业的核心业务痛点，打造一套集客户管理、报价订单、生产排产、车间执行、品质管控、仓储物流、委外加工、财务人事于一体的综合ERP管理平台。

CNC机加工行业具有显著的行业特征：非标定制件多、工序流转复杂、委外加工频繁、图纸管理核心、编程管理依赖历史积累、材料管理需追踪损耗、产能依赖设备状态、品质检测要求严格。传统通用型ERP难以满足这些细分需求，亟需一套贴合行业特点的专业化解决方案。
